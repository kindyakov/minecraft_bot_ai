# Triage labels

Сопоставление ролей навыков с метками трекера:

| Роль | Метка | Значение |
| --- | --- | --- |
| needs-triage | needs-triage | Требуется первичная оценка |
| needs-info | needs-info | Ожидаются уточнения от автора |
| ready-for-agent | ready-for-agent | Задача определена и готова к выполнению агентом |
| ready-for-human | ready-for-human | Требуется выполнение человеком |
| wontfix | wontfix | Решено не выполнять |

Когда навык указывает роль, используй метку из второй колонки.
При смене словаря обновляй сопоставление здесь.

Это конфигурация имён, а не подтверждение существования меток
на GitHub. Перед применением проверь их наличие; создание недостающих
меток выполняй только в рамках разрешённой операции с трекером.
